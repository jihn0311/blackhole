# EVENT HORIZON · 블랙홀 키우기

React와 Canvas로 만든 PC 브라우저 게임입니다.

배포 파일은 `dist/`, 압축 배포본은 `release/event-horizon-web.zip`입니다. 자세한 절차는 [배포 안내](DEPLOY.md)를 참고하세요.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 배포용 파일을 만들고 `npm test`로 성장 규칙과 입력 처리를 검증합니다.

## 조작

천체의 단축키를 누르면 **우주 안에서는 현재 마우스 위치에, 마우스가 우주 밖에 있으면 우주 가장자리의 임의 위치에 소환**합니다. 오른쪽 메뉴에서 선택한 천체는 마우스 왼쪽 버튼으로도 생성할 수 있습니다. 블랙홀 가까이에 소환해도 위치가 강제로 바뀌지 않습니다.

| 키  | 천체   | 키  | 천체   |
| --- | ------ | --- | ------ |
| 1   | 소행성 | 7   | 지구   |
| 2   | 명왕성 | 8   | 천왕성 |
| 3   | 달     | 9   | 토성   |
| 4   | 수성   | 0   | 해왕성 |
| 5   | 화성   | -   | 목성   |
| 6   | 금성   | =   | 태양   |

해금하지 않은 천체와 대기 중인 천체는 생성할 수 없습니다. 숫자 패드도 지원합니다. 우주 공간에 키보드 초점이 있으면 Enter나 Space로 선택한 천체를 생성할 수 있습니다.

**연속 생성 10단계**에서는 마우스 왼쪽 버튼이나 천체 단축키를 누르고 있으면 대기시간이 끝날 때마다 소환합니다. 마우스를 움직이면 소환 위치가 따라갑니다. 입력을 떼거나 우주 공간을 벗어나거나 창 전환·일시정지·메뉴 열기를 하면 반복이 멈춥니다.

## 업그레이드

총 80개 노드가 8개 계열로 이어집니다. 시간 가속 1에서 분기하며 각 계열은 자기 계열의 이전 스킬만 요구합니다. 다른 계열 사이의 중간 연결은 없습니다. 노드를 선택하면 효과·비용·필요한 선행 스킬을 확인할 수 있고, 이미 배운 스킬은 다시 구매할 수 없습니다. 뒤쪽 노드는 포인트 비용이 커집니다.

| 종류        | 최대 단계 | 효과                                                    |
| ----------- | --------: | ------------------------------------------------------- |
| 시간 가속   |        12 | 단계마다 생성 대기시간 15% 감소                         |
| 자동 공급   |        10 | 해금한 천체를 자동 생성, 공급 간격 단축                 |
| 연속 생성   |        10 | 직접 생성 대기시간 감소, 최종 단계에서 누르고 있기 해금 |
| 질량 증폭   |        10 | 흡수 질량이 단계마다 기본값의 15% 증가                  |
| 항성 포식   |        12 | 기본 질량 1,000 M 이상 천체 흡수 배율 단계마다 +10%     |
| 심우주 탐사 |        10 | 반복 탐사 보상 단계마다 +2 P                            |
| 성장 연구   |         8 | 앞으로의 레벨업 보상이 단계마다 1 P 증가                |
| 탐사 보상   |         8 | 앞으로 받는 미션·반복 탐사 보상이 단계마다 1 P 증가     |

질량에 따라 레벨과 천체가 해금됩니다. 순차 미션 10개를 완료한 뒤에는 누적 흡수 100개마다 반복 탐사 보상을 받을 수 있습니다. 도감 12종을 완성한 뒤에도 계속 성장합니다. 자동 공급은 화면이 열려 있을 때 가장 큰 생성 가능한 천체를 우선합니다.

진행 상황은 같은 브라우저에 자동 저장됩니다. 이전 저장 파일의 질량·도감·미션·업그레이드를 유지하며, 삭제된 중력 강화의 구매 포인트는 한 번 환급합니다. 버전 3까지 구매한 일반 강화는 해당 트리 노드를 이미 배운 것으로 처리하고, 이전 영구 강화는 새 영구 트리와 별도로 계속 적용합니다. 기존 포인트와 조각도 유지합니다.

M과 R은 게임용 수치이며 실제 물리 단위가 아닙니다. 질량 증폭 역시 게임 효과입니다. 도감에는 NASA 출처 링크가 포함되어 있습니다. 웹폰트와 NASA 링크는 인터넷 연결이 필요합니다.

## 환생

상단 **환생** 메뉴에서 조건과 보상을 확인합니다. 첫 환생 조건은 기본 천체 12종 도감 발견, 이번 회차 질량 100,000 M 이상, 미사용 일반 포인트 100 P 이상입니다. 다음 회차의 목표 질량은 2배씩 증가합니다. 기본 도감은 유지되므로 다시 수집할 필요가 없습니다.

**특이점 조각 = 환생 직전 미사용 일반 포인트 ÷ 100의 정수 부분**입니다. 예를 들어 137 P는 조각 1개로 변환되고 남는 37 P는 초기화됩니다. 질량이나 이미 소비한 포인트는 조각 보상에 영향을 주지 않습니다. 보상과 초기화 목록을 확인한 후 최종 버튼을 눌러야 환생합니다.

- 초기화: 질량·레벨·일반 포인트·일반 업그레이드·천체의 질량 해금·이번 회차 흡수 횟수·미션·반복 탐사.
- 유지: 도감·최고 질량·환생 횟수·특이점 조각·영구 강화·한 번 해금한 꾹 누르기 기능. 일반 연속 생성 단계와 대기시간 감소는 초기화됩니다.
- 영구 스킬트리: 10개 노드. 영원한 성장에서 시간·연구 두 갈래로 분기하고 영겁의 지평선에서 합쳐집니다. 깊이별 비용은 1 → 2 → 6 → 18 → 54 → 162조각 (총 323개)입니다. 흡수 질량, 소환 속도, 레벨업·미션 보상, 자동 공급, 항성 흡수, 환생 시작 포인트를 강화합니다. 우주의 씨앗을 배우면 다음 환생부터 5 P로 시작합니다.

| 환생 횟수 | 추가 천체 | 회차 내 질량 조건 | 단축키 |
| --------- | --------- | ----------------- | ------ |
| 1         | 적색거성  | 40,000 M          | Q      |
| 2         | 백색왜성  | 90,000 M          | W      |
| 3         | 중성자별  | 200,000 M         | E      |

기본 12종과 환생 천체 3종을 합쳐 총 15종의 도감을 수집할 수 있습니다. 환생 메뉴를 열면 시뮬레이션과 자동 공급이 잠시 멈춥니다. 일반 초기화 버튼은 환생과 달리 영구 기록까지 모두 지우므로 별도의 확인 문구가 표시됩니다.

개발 중 환생 UI를 점검하려면 `/tests/fixtures/prestige.html`을 사용할 수 있습니다. 이 검증 화면은 실제 저장 공간을 읽거나 쓰지 않으며 배포용 빌드에는 포함되지 않습니다.

## 효과음·블랙홀 이미지·레벨 표시

성공한 천체 소환에는 짧은 효과음, 환생 완료에는 저음·화음·잔향을 겹친 효과음이 재생됩니다. 화면 아래의 **소리 켜짐/꺼짐** 버튼으로 음소거할 수 있으며 선택은 브라우저에 저장됩니다. 브라우저 정책에 따라 첫 키보드 또는 마우스 입력 후 소리가 활성화됩니다. Web Audio로 소리를 합성하므로 별도 오디오 다운로드가 필요하지 않습니다.

블랙홀은 사용자가 제공한 이미지를 `src/assets/black-hole.gif`에 원본 그대로 보관하여 표시합니다. 브라우저 이미지 레이어로 GIF 애니메이션을 재생하며, 검은 배경은 우주와 자연스럽게 합성합니다.

레벨 목표와 남은 질량은 K/M 단위 축약 대신 정확한 숫자로 표시합니다. 예를 들어 기존에 모두 `1M`으로 보이던 1,001,100 M과 1,015,300 M을 구분할 수 있습니다. 현재 레벨 내 진행도와 다음 레벨의 누적 목표도 각각 표시합니다.

개발용 `/tests/fixtures/audio.html`에서 소환·환생 소리와 OfflineAudioContext 신호 검증을 실행할 수 있습니다. 검증 화면은 배포용 빌드에 포함되지 않습니다.

## 성장 곡선과 스킬트리 검증

레벨 L에서 다음 레벨까지 필요한 추가 질량은 `80 × L³ + 30 × L² − 10 × L` M입니다. 100 → 740 → 2,400 → 5,560 M로 늘어나며 누적 목표는 100 → 840 → 3,240 → 8,800 M입니다. 같은 질량의 기존 저장은 새 곡선에 따라 레벨이 다시 계산되지만 이미 얻은 포인트는 보존됩니다.

`/tests/fixtures/skills.html`은 저장 데이터에 영향을 주지 않고 두 스킬트리의 구매·잠금·연결을 확인하는 개발용 화면입니다.

## 방사형 스킬트리 조작

일반 스킬 80개와 영구 스킬 10개는 고유한 이름을 사용합니다. 중심 스킬에서 바깥으로 퍼지는 연결을 따라 성장합니다. 각 스킬 위에 커서를 올리거나 키보드로 초점을 맞추면 효과·비용·선행 조건이 표시됩니다. 이름을 누르면 아래에 설명이 남고, 해당 스킬의 구매 버튼으로 그 스킬만 습득합니다.

처음에는 전체 트리가 화면에 맞춰집니다. `＋`, `−`, 배율 슬라이더로 최대 150%까지 확대할 수 있고 `100%`로 이름을 자세히 읽을 수 있습니다. 확대 후 빈 공간을 드래그하거나 스크롤하여 이동하고, `전체 보기`로 돌아옵니다. 기존 구매 기록과 효과는 그대로 유지됩니다.

일반 스킬 비용은 기본 비용 + 2 × 구매 전 계열 단계 + 2 × max(0, 구매 전 계열 단계 − 2)² P입니다. 시간 계열은 1 → 3 → 5 → 9 → 17 → 29 → 45 → 65 → 89 → 117 → 149 → 185 P로 증가합니다. 기존에 구매한 스킬에는 추가 비용이 부과되지 않습니다.

선행 스킬을 모두 배운 다음 노드만 표시되며 이미 배운 노드는 유지됩니다. 일반/영구 트리 배율은 각각 창을 닫았다 열 때 유지됩니다. 포인트 부족 가격은 빨간색으로 표시됩니다. 업그레이드 창을 열면 배경 게임과 자동 공급이 멈춥니다. 자동 공급 10단계는 모든 해금 천체를 각자의 소환 대기시간에 맞춰 동시에 공급합니다.

천체 해금 질량: 소행성 0, 명왕성 100, 달 300, 수성 800, 화성 2,000, 금성 5,000, 지구 12,000, 천왕성 28,000, 토성 65,000, 해왕성 140,000, 목성 300,000, 태양 700,000 M. 환생 천체는 각각 1,500,000 / 3,500,000 / 8,000,000 M 및 해당 환생 횟수가 필요합니다.

## 현재 소환 방식: 쿨타임 자동 생성

해금된 모든 천체는 업그레이드 없이 각자의 쿨타임마다 자동 생성됩니다. 클릭·숫자키·꾹 누르기 소환과 천체 선택은 제거되었습니다. 천체 목록은 남은 쿨타임과 해금 조건만 표시합니다. 일시정지 또는 메뉴를 열면 자동 생성도 멈춥니다.

자동 공급 강화는 단계마다 전체 쿨타임 5%, 연속 생성 강화는 6% 감소를 제공합니다. 연속 생성 최종 단계의 기존 꾹 누르기 보상은 환생 후에도 유지되는 전체 쿨타임 10% 감소로 바뀝니다. 기존 구매 기록은 보존됩니다. 위의 과거 단축키·수동 소환 설명은 이 방식으로 대체되었습니다.

## 확률 강화와 블랙홀 성장 (최신)

쌍성 생성(기존 자동 공급)은 단계마다 추가 생성 확률 +5%p, 최대 50%입니다. 일반 생성 1회에 같은 천체가 최대 1개 더 나오며 재귀 복제는 없습니다. 치명적 흡수(기존 연속 생성)는 단계마다 크리티컬 확률 +4%p입니다. 성공 시 흡수 질량이 2배이며 천체 수는 1개로 계산합니다. 최종 단계의 영구 보너스는 크리티컬 확률 +5%p로 변경되어 총 45%가 되고, 환생 후에도 5%가 남습니다. 기존 구매 단계와 영구 보너스 획득 기록을 유지합니다. 두 계열은 더 이상 소환 쿨타임을 줄이지 않습니다.

해금 질량은 목록 순서대로 0 / 80 / 220 / 550 / 1,300 / 3,000 / 7,000 / 16,000 / 36,000 / 78,000 / 165,000 / 360,000 / 750,000 / 1,600,000 / 3,500,000 M로 낮췄습니다. 소환 쿨타임 자체는 변경하지 않았습니다.

블랙홀 표시 배율은 레벨 L에 따라 `0.38 + 0.62 × (1 − exp(−(L−1)/25))`로 커집니다. 처음에는 작게 시작하고 화면을 벗어나지 않도록 성장 속도가 점차 완만해집니다.

확률 최종 조정: 추가 생성은 단계당 +2%p, 최대 20%로 같은 천체 1개 추가. 크리티컬은 단계당 +0.9%p 및 최종 영구 보너스 +1%p를 합쳐 최대 10%, 흡수 질량 10배입니다. 환생 후 영구 보너스는 1%입니다.

## 중후반 가속과 특이점 폭주

현재 레벨 L에서 다음 레벨로 갈 때 받는 포인트는 기본 2 P + 연구/영구 연구 보너스 + max(0, L−5)² P입니다. 1~5레벨은 그대로이며 기본 기준 10레벨 27 P, 20레벨 227 P가 됩니다. 여러 레벨을 한 번에 넘으면 각 레벨 보상을 합산합니다. 이미 지난 레벨 보상을 소급 지급하지 않습니다.

일반 스킬 80개를 모두 습득하면 환생 전까지 특이점 폭주가 활성화됩니다. 최종 흡수 질량 ×10, 생성 대기시간 ×0.5 (최소 0.12초), 레벨업 포인트 ×3. 보라색 블랙홀 후광과 완료 효과음으로 표시합니다. 크리티컬 확률 10%·질량 10배, 추가 생성 확률 20% 상한은 유지됩니다.

## 자동 생성 해금 방식 (최신)

일반 업그레이드 총 40개부터 1초마다 각 천체의 쿨타임을 확인해 준비된 천체를 모두 자동 소환합니다. 60개부터는 공통 1초 대기 없이 천체별 쿨타임이 끝나는 대로 소환합니다. 쌍성 생성 계열 최종 단계는 추가 생성 확률 20%만 완성하며 자동 생성 해금과는 별개입니다. 그전에는 천체 목록으로 선택한 뒤 우주 공간을 클릭하거나, 마우스 위치와 관계없이 1–9 / 0 / − / = / Q W E로 소환합니다. 마우스가 우주 밖이면 우주 가장자리에서 생성됩니다. 직접 소환은 누를 때마다 1회 시도하며 꾹 누르기 자동 반복은 없습니다. 해금 후에도 직접 소환할 수 있고 천체별 쿨타임을 자동 생성과 공유합니다. 환생하면 일반 업그레이드와 함께 자동 생성도 초기화됩니다. 추가 생성 최대 20%·크리티컬 최대 10% 및 질량 10배는 그대로입니다.

### 천왕성 이후 성장 완화

천왕성부터 기본 흡수 질량을 700 / 1,300 / 2,300 / 4,000 / 12,000 / 24,000 / 60,000 / 150,000 M로 상향했습니다. 천왕성 진입은 16,000 M 그대로이며 이후 해금 목표는 토성부터 32,000 / 66,000 / 132,000 / 275,000 / 560,000 / 1,150,000 / 2,400,000 M입니다. 같은 천체만 쿨타임마다 소환하는 무강화 기준으로 다음 질량 조건까지 걸리는 시간이 이전의 60% 이하가 됩니다. 환생 횟수 조건은 별도입니다. 기존 저장의 질량·포인트·스킬은 유지되며, 새 질량 보상은 앞으로 흡수하는 천체에 적용됩니다.


### 특이점 심화

영구 스킬 10개를 모두 습득한 후 반복 구매할 수 있습니다. 첫 비용은 50조각이고 매번 2배씩 증가합니다. 각 단계마다 심화 질량 보너스가 10%p 증가하며 (×1.1, ×1.2, ×1.3…), 다른 영구 질량 보너스와 곱해집니다. 심화 단계와 기존 조각·구매 스킬은 저장 및 환생 후에도 유지됩니다.

### 업그레이드 중 진행 및 후반 보상

일반 업그레이드 창에서도 천체 흡수·자동 생성·단축키 소환이 계속됩니다. 일시정지, 도감, 환생 화면과 초기화 확인 중에는 진행을 멈춥니다. 일반·영구 트리의 일괄 강화는 현재 재화로 살 수 있고 선행 조건이 열린 스킬부터 저렴한 순서로 구매하며, 추가로 열리는 다음 단계도 포함합니다. 반복 심화는 별도 구매합니다.

반복 탐사 기본 보상은 5 → 10 → 15 → 20 P처럼 완료할 때마다 5 P씩 증가하며 기존 강화 보상이 더해집니다. 환생하면 탐사 횟수와 기본 보상은 초기화됩니다.

15종 전체 도감 완성 시 ‘우주 통달’이 활성화됩니다. 영구 흡수 질량 ×5, 레벨업·미션·반복 탐사 포인트 ×2, 쿨타임 25% 감소 (최소 0.12초)를 적용하며 특이점 폭주와 중첩됩니다. 이미 완성한 저장에도 자동 적용되며, 일회성 포인트를 소급 지급하지 않습니다. 환생 후에도 도감과 보너스가 유지됩니다. 폭주 후광은 블랙홀 중심에서 사라지는 원형 그라데이션으로 표시합니다.

### 환생 메뉴 해금

첫 환생 메뉴는 일반 업그레이드 80개를 모두 습득해야 열립니다. 그전에는 상단 메뉴와 왼쪽 버튼을 자물쇠로 표시하고 클릭 시 ‘모든 업그레이드 해금시 열림’을 안내합니다. 환생 경험이 있는 저장은 메뉴를 계속 이용할 수 있어 영구 강화를 바로 구매할 수 있습니다. 실제 환생은 기존 도감·질량·100 P 조건도 만족해야 합니다.

### 천체 그래픽과 흡수 연출

목록·도감·환생 화면과 소환된 천체에 같은 고해상도 절차적 스프라이트를 사용합니다. 대륙·구름·극지방·분화구·가스 띠·대적점·입체 고리·항성 광채를 천체별로 구분합니다. 텍스처는 최초 한 번 생성해 재사용합니다. 블랙홀에 접근하면 휘는 궤도와 잔상, 진행 방향으로 늘어나는 변형, 축소와 페이드가 적용되며 질량 보상과 흡수 판정은 유지합니다.

첫 환생 이전에 일반 스킬 80개를 완료하면 환생 해금 알림이 표시됩니다. ‘환생 메뉴 보기’ 또는 ‘확인’을 누를 때까지 유지되며, 확인 여부를 저장해 새로고침 후 반복 표시하지 않습니다. 이미 풀강한 첫 회차 저장에도 아직 확인하지 않았다면 표시됩니다.

전체 도감 완성 시 우주 통달 보상을 설명하는 알림이 확인 전까지 유지됩니다. 확인 여부는 저장 및 환생 후에도 유지되며, 관측소에는 우주 통달 활성화와 배율이 계속 표시됩니다.

### 우주의 끝 · 400레벨 엔딩

300 / 320 / 340 / 360 / 380레벨에서 전체 게임 화면과 열린 메뉴 위로 균열·주사선·신호 손상 효과가 단계적으로 심해집니다. 연출 레이어는 클릭을 막지 않습니다. 400레벨 이상이 되면 게임 조작·생성·흡수를 멈추고 완전히 검게 덮은 뒤 3초 후 52초 분량의 엔딩 크레딧을 올립니다. 실제 앱이나 운영체제를 종료시키지 않습니다. 저장된 레벨이 400 이상이면 다시 열 때도 엔딩으로 들어갑니다.

크레딧은 건너뛰거나 다시 볼 수 있으며, 새 우주 시작은 전체 진행 초기화 확인 후 실행됩니다. 동작 줄이기 설정에서는 흔들림을 끄고 크레딧을 수동 스크롤로 읽을 수 있습니다.

크레딧 재생 중 스페이스바를 누르고 있으면 현재 위치에서 4배속으로 진행하고 떼면 원래 속도로 돌아옵니다. 창 전환 시에도 가속이 해제됩니다. 스페이스바로 건너뛰기 버튼이 잘못 눌리지 않도록 처리했습니다.

크레딧 개발 표기는 ‘codex와 j’입니다. 크레딧이 끝나거나 건너뛰면 진행 상황을 그대로 유지한 채 관측소로 복귀하고 게임이 재개됩니다. 엔딩 완료 여부를 저장해 이후 레벨·새로고침·환생에서 붕괴 연출과 크레딧이 반복되지 않습니다. 전체 초기화 시에만 엔딩 완료 기록도 초기화됩니다. 이전의 엔딩 종료 카드와 새 게임 버튼은 제거되었습니다.

크레딧 종료 후 게임으로 돌아오면 ‘발전과제 달성 — 우주에 삼켜진 자’ 알림이 8초간 표시됩니다. 별도 보상이나 능력치 변화는 없습니다.

### 최종 붕괴 및 도감 보상 조정

붕괴는 300~390레벨에서 10레벨 간격으로 총 10단계 진행되고 400레벨에 엔딩으로 전환됩니다. 메뉴의 RGB 어긋남과 짧은 흔들림, 효과음의 음정 양자화와 끊김을 적용합니다. 엔딩 완료 후에는 정상으로 복구됩니다. 전체 도감 15종 완성 보상은 영구 질량 ×50, 포인트 ×5, 쿨타임 60% 감소(최소 0.12초)로 강화했습니다. 기존 완성 저장에도 즉시 적용됩니다.

엔딩 크레딧에는 오리지널 56초 우주풍 배경음악이 재생됩니다. 저음·화음·멜로디가 점차 쌓이며, 종료/건너뛰기 시 짧게 페이드아웃합니다. 음소거 설정을 따르고 스페이스 가속 중에도 음악의 음정과 속도는 유지됩니다. 브라우저 자동재생 제한으로 아직 입력한 적 없는 페이지에서는 첫 클릭/키 입력 후 시작됩니다.

최신 조정: 우주 통달 보상은 질량 ×20, 포인트 ×3, 쿨타임 40% 감소입니다. 크레딧 음악 게인을 0.6에서 1.0으로 올렸습니다(약 +4.4dB, 마스터 음량과 컴프레서는 유지).

엔딩 종류: 일반 엔딩과 해킹 엔딩. 이번 버전부터 jis 사용 기록(cheatUsed)을 저장하며, 치트 사용 후 최초 클리어 시 해킹 연출과 전용 크레딧으로 분기합니다. 이전 버전의 치트 사용은 소급 판정하지 않습니다. 엔딩 종류 메뉴는 기존 엔딩 감상 후 해금되며 획득한 엔딩을 다시 볼 수 있습니다.
